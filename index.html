Hacksoft PowerShell module help

Help for 64-bit Windows PowerShell 5.1, in English and French. The modules include local help at installation.

GPUInfo

Inventory Windows graphics adapters, dedicated memory, drivers and codec reference data.

Get-Help about_GPUInfo
Get-Help GPUInfo\Get-GPU -Examples

HWInformation

Collect a snapshot of the CPU, RAM and graphics adapters.

Get-Help about_HWInformation
Get-Help HWInformation\Get-HWInfo -Examples

VideoTools

Inspect media streams, preview FFmpeg arguments and check capabilities.

Get-Help about_VideoTools
Get-Help VideoTools\New-VideoConversion -Examples

Update the help

Update-Help -Module GPUInfo,HWInformation,VideoTools -UICulture en-US,en-GB,fr-CA,fr-FR

Aide en français

L’aide installée couvre l’inventaire graphique et matériel, le sondage multimédia et la préparation d’arguments FFmpeg. Utilisez Get-Help pour la consulter.

Update-Help -Module GPUInfo,HWInformation,VideoTools -UICulture fr-CA,fr-FR
